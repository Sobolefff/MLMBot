## 🔴 Критично

- [ ] **Эндпоинт логина/рефреша pyapi всё ещё не подтверждён** — блокирует автоматическое подключение аккаунта партнёра. Есть косвенная улика: формат ошибки истёкшего токена — классический `djangorestframework-simplejwt`, значит пути вероятно стандартные (`auth/login/`/`token/`, `auth/refresh/`/`token/refresh/`), но не проверено. **Ни один агент не должен сам вводить пароль пользователя ради разведки** — это только руками самого пользователя через DevTools (см. память `reference-greenway-pyapi`, раздел «НЕ подтверждены», п.1). До тех пор — временный мост: `npm run gw:connect` (кладёт вручную полученный accessToken в БД, зашифровано)
- [ ] **Датацентр-IP среды разработки (Claude Code sandbox) похоже заблокирован Greenway на уровне TLS** (обнаружено 24.09.2026 — см. память `reference-greenway-pyapi`): `npm run gw:sync-catalog` нужно протестировать с обычной машины/сервера пользователя, НЕ из облачной песочницы агента. Если продакшен-хостинг бота тоже в датацентр-диапазоне — синк может не заработать, значит при выборе VPS для деплоя стоит заранее это проверить (тем же `curl -v` до `pyapi.greenwaystart.com`)
